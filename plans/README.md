- **001 first, always.** It creates the `pytest` harness (`tests/conftest.py`
  puts `code/` on `sys.path` and chdirs to the repo root). Plans 002 and 003
  write their tests against that harness.
- **002 and 003 are independent of each other** in code (002 touches only the
  CLI; 003 touches `XrayTransmission.py` + `app.py`). Recommended order is
  002 then 003, but either can go first after 001. They edit disjoint files, so
  they will not conflict.
- **004 last.** It removes the final `icecream` usage and drops the dependency
  from the manifests; it assumes 002 and 003 have already removed `icecream`
  from the CLI and the engine. Its first STOP condition guards this.

## What each plan fixes (one line each)

- **001** — no verification baseline exists; adds data-integrity + Beer–Lambert
  tests that pass on current code (7 tests). Prerequisite for the rest.
- **002** — the CLI crashes on Linux/macOS (Windows backslash paths) and ignores
  its documented positional args; also crashes on off-grid energies.
- **003** — the flagship correctness bug: the Streamlit app applies the last
  filter twice on reruns and shares one mutable `Simulation` across all users,
  producing physically wrong numbers. Fixed by a pure, stateless engine.
- **004** — drops the `icecream` debug-print library (left enabled in the
  library, dumping DataFrames) after 002/003 migrate to `logging`.
